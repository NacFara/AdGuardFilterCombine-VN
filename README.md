## 🪟 Windows hosts

[**Download IPv4 + IPv6 hosts ZIP**](https://raw.githubusercontent.com/NacFara/AdGuardFilterCombine-VN/main/hosts/AdGuardDNSFilterCombine-Windows-Hosts.zip)

Extract the ZIP and merge the text file into `C:\Windows\System32\drivers\etc\hosts`; back up and preserve existing entries. Covers listed hostnames only. Windows does not update it automatically.

> [!IMPORTANT]
> Add the Android/Windows content URLs as **Trusted custom filters**. Use the DNS URL for AdGuard Home or local DNS filtering in an AdGuard app. Some rules depend on platform/client settings.

> Hosted AdGuard DNS has custom-list size limits; this large list is not intended for its standard plans.
